# Cap 1 - Atividade - ATIVIDADE BANCO DE DADOS NA SOCIEDADE 5.0

Esta pasta concentra exclusivamente os artefatos da atividade de Banco de Dados na Sociedade 5.0, mantendo o projeto original separado e preservado.

## Estrutura

- `database/` — scripts Oracle, PL/SQL, dados simulados e testes.
- `backend/` — integração Java/Spring Boot com Oracle.
- `docs/` — DER, documentação técnica, evidências e materiais da entrega.

## Arquitetura da evolução

`Flutter -> API REST Spring Boot -> JDBC -> Oracle -> Functions/Procedures PL/SQL`
